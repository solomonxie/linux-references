# Progressive Permissions Lessons

A step-by-step series learning Linux permissions — users/groups, ACLs,
special bits, and capabilities. Each step is a standalone file.

Steps:

| Step | Topic |
|---|---|
| 01 | `useradd`/`groupadd`, `/etc/passwd`, `/etc/group` |
| 02 | `chmod`, `chown`, octal vs symbolic modes |
| 03 | SUID, SGID, sticky bit |
| 04 | `getfacl`/`setfacl` |
| 05 | advanced: `setcap`/`getcap`, fine-grained root privileges |

# Progressive Permissions Lessons

A step-by-step series learning Linux permissions — users/groups, ACLs,
special bits, and capabilities. Each step is a standalone file.

Steps:

| Step | Topic |
|---|---|
| 01. users groups | `useradd`/`groupadd`, `/etc/passwd`, `/etc/group` |
| 02. chmod chown | `chmod`, `chown`, octal vs symbolic modes |
| 03. suid sgid sticky | SUID, SGID, sticky bit |
| 04. acls | `getfacl`/`setfacl` |
| 05. capabilities | advanced: `setcap`/`getcap`, fine-grained root privileges |

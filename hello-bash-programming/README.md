# Progressive Bash Programming Lessons

A step-by-step series learning bash as a programming language, from basic
scripting up through advanced usage. Each step is a standalone file.

Steps:

| Step | Topic |
|---|---|
| 01. variables io | variables, `read`, basic I/O |
| 02. conditionals | `if`/`[[ ]]`, exit codes |
| 03. loops | `for`, `while`, `until` |
| 04. functions | functions, arguments, return values |
| 05. arrays | indexed and associative arrays |
| 06. string manipulation | parameter expansion, substrings, `[[ =~ ]]` |
| 07. arithmetic | `(( ))`, `$(( ))`, integer math |
| 08. getopts | parsing flags with `getopts` |
| 09. traps signals | `trap`, cleanup on exit/signal |
| 10. heredocs | here-docs and here-strings |
| 11. process substitution | `<(...)`, `>(...)` |
| 12. advanced debugging | advanced: `set -x`/`set -e`/`set -u`, shellcheck |

# Progressive Networking Lessons

A step-by-step series learning Linux networking — iproute2, netfilter,
and network namespaces. Each step is a standalone file.

Steps:

| Step | Topic |
|---|---|
| 01 | `ip addr`, `ip link` |
| 02 | `ip route` |
| 03 | `ip netns` |
| 04 | `iptables` rules and chains |
| 05 | `nftables`, the iptables successor |
| 06 | advanced: veth pairs + a bridge, container-style networking |

# Progressive OpenRC Lessons

OpenRC — the init system Alpine uses instead of systemd — in one file:
`openrc.sh`, sectioned with `----- N. topic -----` markers.

Sections:

| # | Topic |
|---|---|
| 1 | `rc-service`, `rc-status` |
| 2 | `rc-update add/del`, default runlevel |
| 3 | writing a custom `/etc/init.d` script |
| 4 | `need`/`use`/`after` service dependencies |
| 5 | advanced: OpenRC vs systemd unit conversion patterns |

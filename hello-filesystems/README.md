# Progressive Filesystems Lessons

A step-by-step series learning Linux filesystems — ext4, xfs, btrfs, mount
options, inodes, and LVM. Each step is a standalone file.

Steps:

| Step | Topic |
|---|---|
| 01 | filesystem types, `df -T`, `mount` |
| 02 | `mkfs.ext4`, `tune2fs`, `fsck` |
| 03 | `mkfs.xfs`, `xfs_info`, `xfs_growfs` |
| 04 | `mkfs.btrfs`, subvolumes, snapshots |
| 05 | `noatime`, `ro`/`rw`, remounting |
| 06 | inodes, `df -i`, `stat` |
| 07 | advanced: physical/volume/logical volumes, online resize |

# Progressive Filesystems Lessons

A step-by-step series learning Linux filesystems — ext4, xfs, btrfs, mount
options, inodes, and LVM. Each step is a standalone `fs_NN_topic.sh`.

Planned steps (not yet written):

| File | Topic |
|---|---|
| `fs_01_overview.sh` | filesystem types, `df -T`, `mount` |
| `fs_02_ext4_basics.sh` | `mkfs.ext4`, `tune2fs`, `fsck` |
| `fs_03_xfs_basics.sh` | `mkfs.xfs`, `xfs_info`, `xfs_growfs` |
| `fs_04_btrfs_basics.sh` | `mkfs.btrfs`, subvolumes, snapshots |
| `fs_05_mount_options.sh` | `noatime`, `ro`/`rw`, remounting |
| `fs_06_inodes.sh` | inodes, `df -i`, `stat` |
| `fs_07_lvm.sh` | advanced: physical/volume/logical volumes, online resize |

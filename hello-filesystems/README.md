# Progressive Filesystems Lessons

A step-by-step series learning Linux filesystems — ext4, xfs, btrfs, mount
options, inodes, and LVM. Each step is a standalone file.

Steps:

| Step | Topic |
|---|---|
| 01. overview | filesystem types, `df -T`, `mount` |
| 02. ext4 basics | `mkfs.ext4`, `tune2fs`, `fsck` |
| 03. xfs basics | `mkfs.xfs`, `xfs_info`, `xfs_growfs` |
| 04. btrfs basics | `mkfs.btrfs`, subvolumes, snapshots |
| 05. mount options | `noatime`, `ro`/`rw`, remounting |
| 06. inodes | inodes, `df -i`, `stat` |
| 07. lvm | advanced: physical/volume/logical volumes, online resize |

# Progressive Process Management Lessons

A step-by-step series learning Linux process management — signals,
`/proc`, and scheduling. Each step is a standalone file.

Steps:

| Step | Topic |
|---|---|
| 01. ps top | `ps`, `top`/`htop` basics |
| 02. signals | `kill`, `trap`, common signals |
| 03. proc filesystem | `/proc/<pid>/...` internals |
| 04. nice priority | `nice`, `renice`, `ionice` |
| 05. cgroup scheduling | advanced: cgroup v2 `cpu.weight`/`cpu.max` |

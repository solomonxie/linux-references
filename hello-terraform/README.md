# Terraform

Playground for learning Terraform basics and advanced usage. Nothing is
provisioned yet — this is a scaffold for the planned `apply` flow below.
File order doesn't matter — reference order does, see each file's head
comment once written.

```
terraform apply
  ├─ providers.tf   → auth / provider setup
  ├─ variables.tf   → resolve inputs
  ├─ main.tf         → TODO: first resource(s)
  └─ outputs.tf      → TODO: what it prints
```
